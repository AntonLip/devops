
# S3

Цель — понять **Amazon S3** как object storage: модель данных, durability, доступ, шифрование, lifecycle; практика **CLI**, **boto3** и доступ **EC2 → S3** через instance profile.

---

## Теория

### Object storage vs block/file

| | S3 | EBS | EFS |
|--|-----|-----|-----|
| Единица | object (key + bytes) | block sector | file path |
| API | REST/AWS API | attach к OS | NFS mount |
| Latency | миллисекунды–секунды | микросекунды (локально на host) | сетевая NFS |

S3 **не** монтируется как диск (исключение — Mountpoint for S3 FUSE, отдельный продукт).

### Как устроен S3

**Логическая модель:**
- **Bucket** — контейнер с глобально уникальным именем (`my-app-logs-prod-123`).
- **Object** — неизменяемый blob + metadata; идентификатор **key** (`reports/2024/jan.csv`).
- **VersionId** — при включённом versioning каждая перезапись создаёт новую версию.

**Физика (упрощённо для инженера):**
- AWS распределяет объекты по инфраструктуре региона; durability **99.999999999% (11 nines)** за счёт репликации и мониторинга.
- Вы не выбираете AZ для объекта — S3 **regional** service; внутри региона данные распределены автоматически.
- Старый миф «eventual consistency везде» — для **новых** объектов после PUT read-after-write consistent; для overwrite/delete в редких сценариях читайте актуальную документацию AWS.
**Запросы:** каждая операция (PUT, GET, LIST) — отдельный HTTP API вызов; LIST дорог на больших префиксах — проектируйте key prefix (`userId/2024/...`).

### Регион и создание bucket

- Имя bucket **глобально уникально** во всём AWS.
- В **`us-east-1`** `create-bucket` **без** `LocationConstraint`.
- В остальных регионах обязателен `CreateBucketConfiguration.LocationConstraint=eu-central-1`.
Ошибка `IllegalLocationConstraintException` — забыли constraint вне `us-east-1`.

### Доступ и политики

Слои решения «можно ли читать объект»:
1. **Block Public Access** (account/bucket) — запрет публичного ACL/policy.
2. **Bucket policy** (resource-based JSON) — кто может `s3:GetObject` на `arn:aws:s3:::bucket/*`.
3. **IAM policy** (identity-based) — у user/role.
4. **ACL** (legacy) — избегайте в новых системах.

**EC2 без ключей:** IAM role на instance → credentials через IMDS → IAM policy разрешает `s3:PutObject` на конкретный bucket.
**Principal в bucket policy** для доступа с другого account — `Principal.AWS` + `Condition` на ARN role.

### Шифрование

| Тип | Кто держит ключи |
|-----|------------------|
| SSE-S3 (`AES256`) | AWS |
| SSE-KMS | KMS CMK, аудит, квоты API KMS |
| SSE-C | клиент (редко) |

**Bucket Key** для KMS — меньше вызовов KMS, ниже стоимость на массовых PUT.
**Object Lock** — WORM для compliance (retention/legal hold); включать при создании bucket.

### Операции и паттерны

- **Multipart upload** — файлы > 5 GiB или нестабильная сеть; части параллельно, complete в конце.
- **Presigned URL** — временная подпись GET/PUT для браузера/внешнего клиента без IAM user.
- **Versioning** — защита от случайного delete/overwrite; lifecycle может чистить старые версии.
- **Lifecycle rules** — transition в `STANDARD_IA`, `GLACIER`, expiration через N дней.
- **Replication (CRR/SRR)** — асинхронная копия в другой bucket/region (отдельная настройка IAM и replication role).

### Storage classes

| Class | Сценарий |
|-------|----------|
| STANDARD | частый доступ |
| STANDARD_IA | реже, дешевле хранение |
| GLACIER / DEEP_ARCHIVE | архив, минуты–часы retrieval |
| Intelligent-Tiering | автоматический tier по паттерну доступа |

Минимальный размер/время хранения — смотрите pricing (например IA — 30 дней).

### Стоимость

- Хранение (GB-месяц) по class.
- **Requests** (PUT/LIST/GET) — много мелких PUT дороже одного крупного multipart. 
- Transfer out в интернет — отдельная строка в bill.
- Нет платы за «пустой» bucket, но за объекты и запросы — да.

## Практика

```bash
export AWS_PROFILE=lab
export AWS_REGION=eu-central-1
export BUCKET_NAME=devops-lab-s3-$(date +%s)-$RANDOM
```

### 3.1. Create bucket + Block Public Access

```bash
aws s3api create-bucket \
  --bucket "$BUCKET_NAME" \
  --region "$AWS_REGION" \
  --create-bucket-configuration LocationConstraint="$AWS_REGION"

aws s3api put-public-access-block \
  --bucket "$BUCKET_NAME" \
  --public-access-block-configuration \
  BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
```

### 3.2. Upload / list

```bash
echo "hello s3" > /tmp/hello.txt
aws s3 cp /tmp/hello.txt "s3://$BUCKET_NAME/prefix/hello.txt"
aws s3 ls "s3://$BUCKET_NAME/prefix/"
aws s3api head-object --bucket "$BUCKET_NAME" --key prefix/hello.txt
```

### 3.3. Versioning

```bash
aws s3api put-bucket-versioning \
  --bucket "$BUCKET_NAME" \
  --versioning-configuration Status=Enabled

aws s3 cp /tmp/hello.txt "s3://$BUCKET_NAME/prefix/hello.txt"
echo "v2" > /tmp/hello.txt
aws s3 cp /tmp/hello.txt "s3://$BUCKET_NAME/prefix/hello.txt"
aws s3api list-object-versions --bucket "$BUCKET_NAME" --prefix prefix/hello.txt
```

### 3.4. Lifecycle

Файл `lifecycle.json`:

```json
{
  "Rules": [
    {
      "ID": "expire-tmp",
      "Status": "Enabled",
      "Filter": { "Prefix": "tmp/" },
      "Expiration": { "Days": 7 }
    }
  ]
}
```

```bash
aws s3api put-bucket-lifecycle-configuration \
  --bucket "$BUCKET_NAME" \
  --lifecycle-configuration file://lifecycle.json
```

### 3.5. Presigned URL

```bash
aws s3 presign "s3://$BUCKET_NAME/prefix/hello.txt" --expires-in 3600
curl -s "<URL>" | head
```

### 3.6. Encryption default

```bash
aws s3api put-bucket-encryption \
  --bucket "$BUCKET_NAME" \
  --server-side-encryption-configuration '{
    "Rules": [{"ApplyServerSideEncryptionByDefault": {"SSEAlgorithm": "AES256"}}]
  }'
```


## Cost warning

- Storage и requests.
- Versioning увеличивает объём (несколько версий одного key).
- Lifecycle transition — минимальные сроки хранения в IA/Glacier.
- Transfer out.


## Troubleshooting

| Симптом | Причина |
|---------|---------|
| `IllegalLocationConstraintException` | Нужен `LocationConstraint` вне us-east-1 |
| `BucketAlreadyExists` | Имя занято глобально — смените имя |
| `AccessDenied` на EC2 | Role/policy, ARN bucket, Block Public Access |
| `PermanentRedirect` | Неверный regional endpoint для bucket |
| Presigned 403 | Истёк срок, неверный key, clock skew |
| LIST пустой | Неверный prefix, другой bucket |
