# Подготовка серверов

## Цель

Подготовить **Ubuntu 24.04** node к установке Kubernetes: отключить swap, загрузить **kernel modules**, настроить **sysctl**, **IP forwarding**, **bridge netfilter**, hostname/DNS/NTP/firewall - и выполнить всё через скрипт [`./install-kubeadm/scripts/00-prep-node.sh`](./install-kubeadm/scripts/00-prep-node.sh) с пониманием **каждого шага** и безопасным **rollback**.

---

## Теория

### Зачем готовить OS до kubelet

`kubeadm init/join` запускает **preflight checks**. Большинство отказов на первом занятии - **не kubeadm**, а хост:

```
kubeadm preflight
       │
       ├── swap on?              → FAIL
       ├── br_netfilter missing? → WARN/FAIL (CNI)
       ├── ip_forward = 0?       → pod routing broken
       ├── port 6443 in use?     → conflict
       ├── wrong hostname?       → cert/SAN issues
       └── time skew?            → TLS handshake fail
```

**Talos contrast:** Talos **immutable** image уже содержит правильные kernel params и **no swap** - вы не делаете `swapoff` вручную. На kubeadm . **ответственность на админе**.

### CPU, RAM, Storage (повторение + детали)

| Ресурс | Требование | Почему kubelet/kubeadm care |
|--------|------------|------------------------------|
| **CPU** | 2+ vCPU | static pods, CNI, image pulls parallel |
| **RAM** | 4–8 GiB CP | etcd `quota-backend-bytes`, OOM score |
| **Disk** | SSD, 30+ GiB free | `/var/lib/kubelet`, `/var/lib/containerd`, images |
| **Inodes** | достаточно | many small layers |

**kubelet reservations (production):**

```yaml
# /var/lib/kubelet/config.yaml (позже kubeadm создаст)
systemReserved:
  cpu: 500m
  memory: 1Gi
kubeReserved:
  cpu: 500m
  memory: 1Gi
```

можно не задавать вручную - kubeadm defaults; в prod - **обязательно**, иначе user Pod вытеснит system Pod.

### Hostname и DNS

**Hostname** → имя **Node object** в Kubernetes (`kubectl get nodes`).

| Правило | Пример |
|---------|--------|
| Уникальный в кластере | `k8s-cp-01`, не `ubuntu` |
| Lowercase, DNS-1123 subset | `k8s-w-01` OK |
| Stable across reboot | не менять после join без drain |

**DNS / /etc/hosts:**

- nodes должны **resolve** друг друга по имени для human ops;
- для join достаточно IP, но **NTP hostname** и **advertise address** зависят от stable networking.

```
/etc/hosts (.):
192.168.1.20  k8s-cp-01
192.168.1.21  k8s-w-01
```

**Contrast Talos:** machine config задаёт `hostname` declarative; drift невозможен через SSH.

### NTP (время)

TLS certificates (kubeadm PKI, kubelet client certs) valid only в окне ±5 мин (типично).

```bash
timedatectl status
# System clock synchronized: yes
# NTP service: active
```

**Симптом skew:** `x509: certificate has expired or is not yet valid`, etcd **leader election** flapping.

### Firewall

**.:** часто `ufw disable` для скорости обучения.

**Production:** allowlist между node subnet:

| From | To | Ports |
|------|-----|-------|
| workers | CP | 6443, 9443 (if konnectivity) |
| CP ↔ CP | CP | 2379-2380, 10250 |
| all nodes | all nodes | 10250, CNI ports |

**Не открывайте 6443 в интернет** без понимания - API auth обязателен, но scan/bruteforce не нужны.

### Swap

**Исторически:** kubelet отказывался стартовать со swap.

**Сейчас (1.32):** можно **limited swap** с `failSwapOn: false` + feature gate - **не для .**.

**. approach:** swap **off** полностью - предсказуемость как в CKA exam.

```
Memory pressure без swap:
  kubelet evicts user Pods (QoS order: BestEffort → Burstable → Guaranteed)
  system-critical pods protected via priorityClass
```

**Почему Kubernetes не любит swap:** cgroup memory limits и OOM semantics ломаются; latency для etcd unacceptable.

**Действия:**

```bash
swapoff -a
# удалить swap из /etc/fstab
sed -i '/ swap / s/^\(.*\)$/#\1/' /etc/fstab
```

### Kernel modules: overlay, br_netfilter

| Module           | Зачем                                                           |
| ---------------- | --------------------------------------------------------------- |
| **overlay**      | overlay2 storage driver для container layers                    |
| **br_netfilter** | bridge traffic через iptables/nftables (Service, NetworkPolicy) |

```bash
modprobe overlay
modprobe br_netfilter
```

**Persistent:**

```bash
# /etc/modules-load.d/k8s.conf
overlay
br_netfilter
```

**Проверка:**

```bash
lsmod | grep -E 'overlay|br_netfilter'
```

### sysctl и network

Файл **`/etc/sysctl.d/99-kubernetes-cri.conf`** (стандарт kubeadm docs):

| Parameter                             | Значение | Зачем                                       |
| ------------------------------------- | -------- | ------------------------------------------- |
| `net.bridge.bridge-nf-call-iptables`  | 1        | bridged pod traffic видит iptables (legacy) |
| `net.bridge.bridge-nf-call-ip6tables` | 1        | IPv6                                        |
| `net.ipv4.ip_forward`                 | 1        | routing между pod ↔ node ↔ world            |
|                                       |          |                                             |

```
Pod (10.244.1.5) ──veth──► cni0/bridge ──► eth0 ──► other node
                              │
                    ip_forward=1 на node
                    bridge-nf-call-iptables=1
```

**Применение:**

```bash
sysctl --system
sysctl net.ipv4.ip_forward net.bridge.bridge-nf-call-iptables
```

**Contrast Cilium eBPF:** часть правил иначе, но **ip_forward** всё равно нужен на Linux router nodes.

### iptables vs nftables (Ubuntu 24.04)

Ubuntu 24.04 может использовать **nftables** backend. kube-proxy и Calico historically iptables; проверяйте совместимость версий CNI.

**.:** следуем kubeadm + Calico manifest docs для 1.32.

### Полная схема подготовки node

```
Ubuntu 24.04 fresh install
         │
         ├── hostname + /etc/hosts
         ├── NTP sync
         ├── swap OFF
         ├── modules: overlay, br_netfilter
         ├── sysctl: ip_forward, bridge-nf-call-*
         ├── (optional) disable ufw
         │
         ▼
    Ready for containerd (15.5.3)
         │
         ▼
    Ready for kubelet (15.5.4)
         │
         ▼
    kubeadm init/join (15.5.5+)
```

### Production best practices

| Практика | Детали |
|----------|--------|
| **Immutable baseline** | Packer/Ansible image с prep уже внутри |
| **No manual drift** | всё через IaC, не «ssh и поправил» |
| **Separate disk for etcd** | dedicated mount `/var/lib/etcd` |
| **Disable unattended upgrades** на kube nodes | или maintenance window + drain |
| **AppArmor/SELinux** | Ubuntu AppArmor default - не ломать profiles CNI |
| **Audit before join** | один script на все nodes |

**Типичные ошибки:**

- swap включился после reboot (fstab не правили);
- sysctl не persistent (забыли `/etc/sysctl.d/`);
- duplicate hostname → второй node **перезаписывает** первый в API;
- MTU mismatch в overlay (1472 vs 1500) - отдельная глава troubleshooting.

## Практика

### Цель

На **каждой** VM . (k8s-cp-01, k8s-w-01, k8s-w-02) выполнить подготовку через скрипт и **вручную** проверить ключевые параметры.

### Зачем

Preflight kubeadm **повторяет** эти проверки - лучше понимать их до fail.

### Шаг 1 - скопировать . scripts на VM

```bash
# С рабочей машины (или git clone course repo)
scp -r "./install-kubeadm/scripts/" k8s-cp-01:/tmp/install-kubeadm/
# Повторить для workers
```

### Шаг 2 - запустить prep script

На **каждой** node (as root):

```bash
cd /tmp/install-kubeadm/scripts
chmod +x 00-prep-node.sh
sudo ./00-prep-node.sh
```

**Что делает `00-prep-node.sh` (ожидаемое содержание):**

| Шаг | Действие |
|-----|----------|
| 1 | `swapoff -a`, comment fstab |
| 2 | load `overlay`, `br_netfilter` + modules-load.d |
| 3 | write `/etc/sysctl.d/99-kubernetes-cri.conf` |
| 4 | `sysctl --system` |
| 5 | optional: disable ufw |
| 6 | verify: swap, modules, sysctl |

### Шаг 3 - ручная верификация

```bash
# Swap
swapon --show                    # пусто
grep -v '^#' /etc/fstab | grep swap || echo "OK: no swap in fstab"

# Modules
lsmod | grep overlay
lsmod | grep br_netfilter

# Sysctl
sysctl net.ipv4.ip_forward
sysctl net.bridge.bridge-nf-call-iptables

# Hostname
hostnamectl

# Time
timedatectl | grep synchronized
```

**Ожидаемый результат:**

```
net.ipv4.ip_forward = 1
net.bridge.bridge-nf-call-iptables = 1
System clock synchronized: yes
```

### Шаг 4 - reboot test (важно!)

```bash
sudo reboot
# после reboot - повторить шаг 3
```

**Зачем:** убедиться, что modules/sysctl **persistent**.

### Шаг 5 - contrast с Talos (read-only, рабочая машина)

```bash
kubectl get nodes -o json | jq '.items[] | {name:.metadata.name, kernel:.status.nodeInfo.kernelVersion, os:.status.nodeInfo.osImage}'
```

Talos nodes уже **prepared** - сравните OS image vs Ubuntu manual prep.

### Verify (чеклист)

| Check | CP | w-01 | w-02 |
|-------|----|------|------|
| swap off | ✓ | ✓ | ✓ |
| ip_forward=1 | ✓ | ✓ | ✓ |
| br_netfilter | ✓ | ✓ | ✓ |
| unique hostname | ✓ | ✓ | ✓ |
| NTP sync | ✓ | ✓ | ✓ |

### Rollback

**Откат prep (если нужно вернуть VM в «до K8s» state):**

```bash
# 1. Включить swap обратно (если был)
sudo sed -i 's/^#\(.* swap .*\)/\1/' /etc/fstab
sudo swapon -a

# 2. Удалить k8s sysctl
sudo rm -f /etc/sysctl.d/99-kubernetes-cri.conf
sudo sysctl --system

# 3. Удалить modules-load
sudo rm -f /etc/modules-load.d/k8s.conf

# 4. Ufw (если отключали)
sudo ufw enable   # только если понимаете правила

# 5. Reboot
sudo reboot
```

**Полный rollback . VM:** snapshot hypervisor **до** prep - быстрее для учебного стенда.

## Что произошло внутри Kubernetes

**Пока kubelet не установлен** - Kubernetes не участвует. Меняется **Linux host**:

```
00-prep-node.sh
      │
      ├── swapoff → ядро не использует disk как RAM
      │             kubelet (позже) preflight PASS
      │
      ├── modprobe overlay → containerd сможет mount layers
      │
      ├── modprobe br_netfilter → pod bridge traffic + iptables
      │
      └── sysctl ip_forward=1 → Calico/CNI маршрутизация между pods/nodes

После kubelet + CNI:
      │
      └── эти параметры определяют, дойдёт ли packet от Pod A на node1
          до Pod B on node2
```

## Troubleshooting

| Симптом | Причина | Решение |
|---------|---------|---------|
| `[ERROR Swap]: running with swap on` | swap active | `swapoff -a`, fstab |
| `modprobe: br_netfilter not found` | old kernel / module name | kernel 5.x+, `apt install linux-modules-extra` |
| `sysctl: cannot stat` | file not loaded | `sysctl --system`, path `/etc/sysctl.d/` |
| After reboot swap returns | fstab | comment swap line |
| Nodes same name in `kubectl get nodes` | duplicate hostname | fix **before** join |
| TLS errors later | NTP | `timedatectl set-ntp true` |
| Pod network works node-local only | ip_forward=0 | sysctl |
| Calico IPAM OK, no cross-node ping | firewall/MTU | ufw, MTU 1450 VXLAN |
